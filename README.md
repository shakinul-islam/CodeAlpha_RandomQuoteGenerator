# CodeAlpha_RandomQuoteGenerator | Daily Zen 🌿

A minimalist, high-end random quote generator app built with Flutter. Inspired by premium meditation and mindfulness apps like Calm and Headspace, **Daily Zen** offers a serene user experience with smooth animations, elegant typography, and a deeply polished UI.

This project is submitted as **Task 2 (Random Quote Generator)** for the App Development Internship at **CodeAlpha**.

## ✨ Features

### Core Requirements (CodeAlpha Task 2)
- ✅ **Instant Display:** Displays a random quote immediately every time the user opens the app (using cached data while fetching a new one).
- ✅ **New Quote Button:** Features a "Breathe & Renew" button that fetches and shows a different quote on each click.
- ✅ **Clear Content:** Displays the quote text and the author's name clearly using premium typography (Playfair Display & Inter).
- ✅ **Minimalist UI:** A completely clean, minimal UI with lots of whitespace, subtle background watermarks, and elegant design.

### Premium Add-ons 🚀
- 🌓 **Dark & Light Mode:** Smooth theme toggling for day and night usage.
- 💾 **Offline Caching:** Saves the last fetched quote so the app never shows a blank screen on launch.
- ❤️ **Favorites System:** Users can bookmark/save their favorite quotes locally.
- 📋 **Copy & Share:** One-tap copy to clipboard and share functionality using `share_plus`.
- 💫 **Smooth Animations:** High-end fade and slide transitions using `flutter_animate`.
- 📱 **Native Splash Screen:** Customized native splash screen seamlessly transitioning into the app.
- 📳 **Haptic Feedback:** Subtle vibrations on button presses for a premium tactile feel.

## 🛠️ Tech Stack & Packages

- **Framework:** Flutter (Dart)
- **State Management:** Riverpod (`flutter_riverpod`)
- **Networking:** Dio (Fetching quotes from DummyJSON API)
- **Local Storage:** Shared Preferences (Caching & Favorites)
- **UI & Animations:** `google_fonts`, `flutter_animate`
- **Native Customization:** `flutter_native_splash`, `flutter_launcher_icons`
